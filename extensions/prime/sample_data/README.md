## Sample data

This directory contains code for evaluating Borzoi Prime on a small sample of the original training data, which includes 3 pseudo-bulked scRNA-seq tracks for human and mouse respectively.
As a prerequisite, download the [sample dataset](https://storage.googleapis.com/seqnn-share/prime/sample_data/prime-sample-data.tar.gz) and uncompress it at the relative file path 'data/v11s/'.
